Забыл пароль?

⚙️ Для работы нужна настройка Firebase

Чтобы сервис работал по-настоящему:
1. Зайди на console.firebase.google.com
2. Создай проект → включи Authentication (Email/Password) + Realtime Database + Storage
3. Скопируй конфиг и замени в коде ниже блок FIREBASE_CONFIG
4. В правилах БД поставь: "rules": {".read": "auth != null", ".write": "auth != null"}

Без этого работает демо-режим с тестовыми данными.
